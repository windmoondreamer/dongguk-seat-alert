# 동국대 도서관 빈자리 카카오톡 알림

원하는 열람실 좌석에 빈자리가 생기면 **카카오톡 "나에게 보내기"**로 알려줍니다.
메시지의 **예약하러 가기** 버튼을 누르면 도서관 좌석 페이지가 열리고, 예약은 직접 합니다.

- **알림만 보냅니다.** 예약이나 취소는 하지 않습니다.
- 본인 **Cloudflare 무료 계정**에서 돌아갑니다. 컴퓨터나 폰을 꺼도 계속 동작합니다.
- 1분마다 실행되고, 한 번 실행할 때 20초 간격으로 3번 확인합니다. 같은 자리는 5분 안에 다시 알리지 않습니다.
- 학교 공식 서비스가 아닙니다. 도서관 시스템이 바뀌면 동작하지 않을 수 있습니다.

```
🟢 보덕열람실 빈자리: A12
현재 빈자리: A12, A3
(14:05:20)
[예약하러 가기]
```

---

## 준비물 (전부 무료)
1. **Node.js 20 이상**: https://nodejs.org 에서 LTS 설치
2. **Cloudflare 계정**: https://dash.cloudflare.com/sign-up
   - 처음 쓰는 계정이면 대시보드 → **Workers & Pages**에 한 번 들어가 workers.dev 서브도메인을 만들어 두세요.
3. **동국대 도서관 계정** (학번·비밀번호)
4. **카카오 개발자 앱**: 아래 "카카오 앱 준비" 참고

## 카카오 앱 준비 (한 번, 약 5분)
https://developers.kakao.com 에 카카오 계정으로 로그인한 뒤 진행합니다. 메뉴 이름은 콘솔 개편에 따라 조금 다를 수 있습니다.

1. **내 애플리케이션 → 애플리케이션 추가**: 앱 이름은 아무거나 (예: 도서관알림)
2. **앱 키**: **REST API 키**를 복사합니다. JavaScript 키나 네이티브 앱 키가 아닙니다.
3. **카카오 로그인**: **활성화 ON**
4. **Redirect URI** 등록: 카카오 로그인 메뉴, 또는 **앱 키 → REST API 키 상세** 화면에 있습니다.
   ```
   http://localhost:8765/callback
   ```
   `http`(s 없음), `localhost`, 포트 `:8765`, 끝에 `/` 없음. 정확히 이대로 입력하세요.
5. **카카오 로그인 → 동의항목**: 아래 **접근권한** 구역의 **카카오톡 메시지 전송** → 설정 → **선택 동의**, 동의 목적은 아무 설명 → 저장
6. **플랫폼 → Web → 사이트 도메인**에 `https://lib.dongguk.edu` 등록 (등록하지 않으면 "예약하러 가기" 버튼이 동작하지 않음)
7. **보안 → 클라이언트 시크릿**: **카카오 로그인** 줄이 **ON**이면 그 코드를 복사합니다(비즈니스 인증 코드가 아님). OFF면 필요 없습니다.

## 설치
이 폴더에서 실행합니다.
```
npm install
npm run setup
```
질문에 차례로 답하면 됩니다.
1. Cloudflare 로그인 (브라우저에서 Allow)
2. 열람실 번호 선택
3. 학번·비밀번호 (로그인을 바로 확인하고 좌석 목록을 보여줌)
4. 알림 받을 좌석: `A1-A12`, `A1-A12, B3`, `all` 형식
5. 알림을 끌 시간대 (예: `00:00-07:00`, 없으면 Enter)
6. 카카오 REST API 키, Client Secret → 브라우저에서 동의 → 카톡 테스트 메시지 수신
7. Worker 이름 (Enter = `seat-alert`) → 배포 → 동작 확인

"완료!"가 나오면 1~2분 안에 카톡으로 "빈자리 감시 시작" 메시지가 옵니다.
설정(열람실, 좌석, 시간대)을 바꾸려면 `npm run setup`을 다시 실행하세요. 같은 Worker를 새 설정으로 덮어씁니다.

## 사용
| 명령 | 하는 일 |
|---|---|
| `npm run status` | 지금 빈자리와 동작 상태 확인 |
| `npm run off` | 알림 끄기 |
| `npm run on` | 알림 다시 켜기 |
| `npm run logs` | 실시간 로그 보기 (Ctrl+C로 종료) |

도서관 비밀번호를 바꿨다면 `npx wrangler secret put LIB_PW`로 새 비밀번호를 넣어야 알림이 계속 옵니다.

## 카카오 오류
브라우저에 `KOE` 코드가 뜰 때 확인할 곳입니다.

| 코드 | 원인 | 해결 |
|---|---|---|
| KOE205 | 메시지 전송 동의항목 미설정 | 준비 5번 |
| KOE006 | Redirect URI 불일치 | 준비 4번: 주소를 한 글자씩 비교 |
| KOE004 | 카카오 로그인 꺼짐 | 준비 3번 |
| KOE101 | 키 오류 | REST API 키를 넣었는지 확인 |
| KOE010 / client_secret | Client Secret 필요 | 준비 7번의 코드를 setup에 입력 |

고친 뒤 `npm run setup`을 다시 실행하세요.

## 보안과 주의
- 도서관 비밀번호와 카카오 키는 **본인 Cloudflare 계정의 암호화된 Secret**에만 저장됩니다. 이 폴더에는 남지 않습니다.
- 이 폴더를 다른 사람에게 줄 때는 `node_modules`, `wrangler.toml`, `.admin.json`을 빼고 주세요(`.gitignore`에 등록돼 있음).
- 카카오 토큰은 실행 중에 자동으로 갱신됩니다. 다만 2개월 넘게 꺼 두었다면 `npm run setup`을 다시 하세요.
- 무료 요금제 KV 쓰기 한도는 하루 1,000회입니다. 빈자리 목록이 바뀔 때만 기록하므로 보통은 충분합니다. 다만 `all`처럼 좌석을 많이 고르면 한도에 걸리거나 알림이 지나치게 많아질 수 있습니다.
- 도서관 서버 부담을 줄이기 위해 확인 간격(20초)은 더 줄이지 마세요.
- 동작 확인: 2026-10-09, 중앙도서관 보덕열람실
